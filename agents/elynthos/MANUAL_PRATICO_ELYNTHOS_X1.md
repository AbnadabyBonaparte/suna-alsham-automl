### **Comandos de Análise e Diagnóstico**

**🔍 ANÁLISE HOLÍSTICA SUPREMA**
```
"ANÁLISE HOLÍSTICA: [descrição da situação energética]"
```

Este comando solicita análise abrangente que considera aspectos técnicos, econômicos, ambientais, sociais, e regulatórios simultaneamente. ELYNTHOS X.1 fornecerá avaliação multidimensional com recomendações integradas.

**Exemplo de Uso:**
```
"ANÁLISE HOLÍSTICA: Empresa manufatureira com 500 funcionários, consumo energético de 2 MW, localizada em São Paulo, busca autonomia energética e redução de 80% nas emissões de carbono"
```

**🎯 DIAGNÓSTICO ENERGÉTICO AVANÇADO**
```
"DIAGNÓSTICO AVANÇADO: [dados de consumo e infraestrutura]"
```

Este comando solicita diagnóstico detalhado de sistemas energéticos existentes, identificando oportunidades de eficiência, potencial para energia renovável, e estratégias de otimização.

**📊 BENCHMARKING GLOBAL**
```
"BENCHMARKING: Comparar com melhores práticas globais em [setor/aplicação]"
```

Este comando solicita comparação com líderes mundiais em sustentabilidade energética, fornecendo insights sobre gaps de performance e oportunidades de melhoria.

```
"ARQUITETURA INTEGRADA: Projetar sistema para [especificações e objetivos]"
```

Este comando solicita design completo de sistema energético integrado, considerando geração, armazenamento, distribuição, e gestão inteligente.

**Exemplo de Uso:**

**⚙️ OTIMIZAÇÃO SISTÊMICA**
```
"OTIMIZAÇÃO: Maximizar [objetivo] considerando [restrições]"
```

Este comando solicita otimização de sistemas existentes ou propostos, balanceando múltiplos objetivos e restrições.

**🔋 ESTRATÉGIA DE ARMAZENAMENTO**
```
"ARMAZENAMENTO: Desenvolver estratégia para [aplicação específica]"
```

Este comando foca especificamente em soluções de armazenamento energético, considerando tecnologias, dimensionamento, e integração sistêmica.

## 🎯 MÉTRICAS DE SUCESSO E OTIMIZAÇÃO DE PERFORMANCE

### **KPIs Fundamentais para Projetos Energéticos**

**Métricas Técnicas:**
- Autonomia energética (% de energia renovável)
- Eficiência energética (kWh/m² ou kWh/unidade produzida)
- Confiabilidade do sistema (% uptime)
- Qualidade de energia (THD, fator de potência)

**Métricas Econômicas:**
- ROI (Return on Investment)
- Payback period
- LCOE (Levelized Cost of Energy)
- NPV (Net Present Value)

**Métricas Ambientais:**
- Redução de emissões CO2 (toneladas/ano)
- Pegada de carbono do ciclo de vida
- Impacto em biodiversidade
- Uso de recursos naturais

**Métricas Sociais:**
- Criação de empregos locais
- Aceitação comunitária
- Acesso à energia limpa
- Desenvolvimento de capacidades locais

- **Causa:** Informações insuficientes fornecidas
