## 🛠️ COMO USAR - PASSO A PASSO

### **PASSO 1: DEFINIÇÃO DO PROJETO PUBLICITÁRIO**

**O que você precisa definir:**
```
✅ Objetivo comercial (vendas, leads, awareness, app installs)
✅ Orçamento total disponível (diário/mensal)
✅ Público-alvo principal (idade, localização, interesses)
✅ Produto/serviço a ser promovido
✅ Plataformas preferenciais (ou deixar OMNEKY X.0 escolher)
✅ Prazo da campanha (contínua, sazonal, específica)
```

**Exemplo de briefing:**
> "Quero vender meu curso online de marketing digital. Orçamento: R$ 10.000/mês. Público: empreendedores 25-45 anos, Brasil. Objetivo: 100 vendas/mês a R$ 497 cada. Prazo: campanha contínua."
